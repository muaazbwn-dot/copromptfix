# Promptify Gallery

Create a professional, aesthetic website called PromptHell.

Concept

PromptHell is a website where people can discover AI image prompts by browsing example images.

The website does NOT generate or edit images.

The main experience is:

Browse images → Click an image → See its prompt → Copy the prompt

The website will earn money only through advertisements.

There should be no premium system, subscriptions, paid credits, or paid features.

Homepage

Create a beautiful, modern homepage with a premium visual design.

At the top, display the website name:

Promptify

Add a short tagline such as:

"Discover. Copy. Create."

Hero section

Create a large hero section with a slideshow/carousel of beautiful AI-generated example images in the background.

The images should automatically change every few seconds with smooth transitions.

Place the PromptHell title and tagline over the hero section.

Add a prominent search bar:

"Search prompts..."

Prompt Gallery

Below the hero section, create a large image gallery similar to a professional online marketplace.

Display images as attractive cards.

Each card should contain:

Image

Short title

Category

Small "View Prompt" button

Use a responsive masonry/grid layout.

The images should be the main focus.

Make the gallery look premium, clean and aesthetic.

Prompt Details

When a visitor clicks an image, open a beautiful prompt details page/modal.

Show:

Large image

Prompt title

Full prompt

Category

Tags

Creator name

Copy Prompt button

Share button

The prompt should be displayed inside a clean text box.

Copy button

When the user clicks:

Copy Prompt

automatically copy the complete prompt to their clipboard.

After copying, show a small confirmation:

"Prompt copied!"

No login should be required.

Categories

Create categories so users can easily discover prompts.

Examples:

Realistic

Anime

Cinematic

Fantasy

Portrait

Nature

Architecture

Cars

Animals

Fashion

Product Photography

3D

Illustration

Allow users to filter the gallery by category.

Search

Add a fast search function.

Users should be able to search by:

Prompt title

Prompt text

Category

Tags

Show relevant results in the gallery.

Upload New Prompt

Add a highly visible:

+ Upload Prompt

button.

Users should be able to submit:

Image

Prompt

Title

Category

Tags

Creator name (optional)

Submission process

After submission:

Do NOT immediately publish the content.

Send submitted prompts to a moderation queue.

Create an admin area where the website owner can:

Approve submissions

Reject submissions

Delete submissions

Edit submissions

Feature selected prompts

Only approved prompts should appear publicly.

Users should NOT need to create an account to submit a prompt.

Trending & Latest

Create sections such as:

🔥 Trending Prompts

Show prompts with the highest views/copies.

✨ Latest Prompts

Show the newest approved submissions.

⭐ Featured Prompts

Allow the administrator to manually select featured prompts.

Advertisement Monetization

The ONLY monetization method should be advertisements.

Do NOT create:

Premium plans

Subscriptions

Paid prompts

Credits

Purchases

Paywalls

Prepare appropriate spaces for Google AdSense.

Advertisements should never interfere with the main experience.

Do not place ads where they could be confused with:

Images

Copy buttons

Download buttons

Navigation

Search results

Design

The website should look like a professional modern design platform, not a basic blog.

Use:

Elegant typography

Beautiful spacing

Smooth animations

High-quality image presentation

Rounded cards

Subtle shadows

Smooth hover effects

Responsive navigation

Dark/light aesthetic that fits the brand

Mobile-first responsive design

The images should be the visual focus.

Avoid making the website overly complicated.

Navigation

Create a clean navigation bar:

Promptify | Explore | Categories | Upload | Search

Add a footer containing:

About

Contact

Privacy Policy

Terms of Service

Copyright information

Mobile

Make the entire website work beautifully on mobile.

The gallery should automatically adapt to screen size.

The image viewer and prompt box must be easy to use on a phone.

The Copy Prompt button should be large enough to tap easily.

SEO

Make every prompt have its own SEO-friendly page/URL.

For example:

/prompt/cinematic-car-photography

Add:

SEO title

Meta description

Open Graph image

Proper headings

Sitemap

Robots.txt

Canonical URLs

Structured data where appropriate

Make prompt pages indexable by Google.

Analytics

Integrate Google Analytics so the website owner can see:

Visitors

Countries

Devices

Traffic sources

Most viewed prompts

Most copied prompts

Popular categories

Uploads

Daily/monthly traffic

Also make the website compatible with Google Search Console.

Database

Create a database containing:

Prompt ID

Image

Title

Prompt text

Category

Tags

Creator

Views

Copy count

Upload date

Approval status

Featured status

Track prompt views and copy counts so the website can determine trending prompts.

Important

The website must be designed around discoverability and Google traffic.

Each prompt should have a useful individual page that people can find through search engines.

The website should be fast even when there are thousands of images.

Optimize and lazy-load images.

Do not use AI to generate the website's prompt content automatically.

The final result should feel like a professional visual prompt discovery platform.

Main user journey

Open Promptify → See beautiful image slideshow → Browse image gallery → Click an image → Read prompt → Copy prompt → Continue browsing.

Also provide:

Upload Prompt → Moderation → Approval → Prompt appears in gallery.
